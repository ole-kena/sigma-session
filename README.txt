SIGMA SESSION V2 — FIRST PWA BUILD

Included:
- Independent V2 PWA project; supplied V1 archive is not modified.
- User-provided pencil-art image adapted as 192px and 512px app icons.
- Local clock and timezone display.
- XAU/USD weekend status estimate (Sunday 17:00 to Friday 17:00 New York time).
- ICT killzone dashboard, live countdowns and animated progress bar.
- Editable killzone start/end hours.
- Integrated SIGMA LOTS CALCULATOR V1.4 logic and supported instruments.
- Manual economic-calendar event foundation (not a live news feed).
- Local settings and offline app shell.

IMPORTANT LIMITATIONS / NEXT WORK:
1. Weekend market hours vary by broker. The included schedule is a common estimate and must be checked against your broker's XAUUSD contract/trading hours.
2. The supplied V1 killzone defaults were retained: Asia 20:00–24:00, London 02:00–05:00, New York 07:00–10:00, New York local time. Confirm these are the windows you want.
3. Lot calculator assumptions are carried over from the supplied V1.4 calculator: XAUUSD 100 oz/lot; FX 100,000 base units/lot; USD account; round down to 0.01 lot. Verify your broker contract/tick values.
4. Economic calendar is a manual event foundation, not live economic-data integration.
5. Browser notifications can be unreliable when the app/browser is closed. Reliable native Android alarms require the next Capacitor/native Android phase.
6. Install PWA from an HTTPS host. To test locally, use a local web server; service workers do not run from file://.

The original sigma-session-main.zip and sigma_lots_calculator_v1_4.zip are separate source archives and are not altered by this output.
